# Chrome Web Store Metadata Templates

These files are copied to `dist/extension/webstore/` when you run:

```bash
npm run extension:package
```

Use them to fill in the Chrome Web Store listing quickly.

Files:
- `listing-short-description.txt`
- `listing-description.md`
- `privacy-policy.md`
- `release-notes.md`

You can paste these into the Web Store listing fields.
